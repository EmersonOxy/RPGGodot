RPGGodot - Medieval Smooth Stone Floor

Esta versão corrige o problema de ficar "quadriculado".
Em vez de ladrilhos quadrados, o padrão usa pedras irregulares,
com aparência medieval e superfície relativamente lisa, ideal para interiores.

Arquivos:
- medieval_smooth_stone_albedo.png
- medieval_smooth_stone_normal.png
- medieval_smooth_stone_roughness.png
- medieval_smooth_stone_material.tres
- medieval_smooth_stone_preview_2x2.png

Coloque em:
res://assets/environment/medieval_smooth_stone/

Configuração inicial sugerida:
- Texture Repeat: On
- UV1 Scale: 4.5, 4.5, 4.5
- Normal Scale: 0.95
- Roughness: 0.72

Ajustes:
- Mais pedras grandes = diminuir UV1 Scale
- Mais repetição / pedras menores = aumentar UV1 Scale
